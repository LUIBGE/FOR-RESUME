🔄 团队数据同步（T盘）
使用 T盘 实现团队数据共享
1. 点击「导出数据包」下载 JSON 文件
2. 将文件上传到 T盘（或发到团队群）
3. 团队成员下载后点击「导入数据包」
4. 系统自动合并冲突，保留最新数据
📥 导入团队数据包
支持从 T盘 下载的 warehouse-data-*.json 文件
合并规则：
• 新物品：直接添加
• 已有物品：保留修改时间较新的版本
• 借出记录：按 ID 去重合并，不丢失历史
